# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues for `PheadDodo/Green_CV`. Use the `gh` CLI for issue operations from this clone.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its comments with `gh issue view <number> --comments`.
- List and filter issues with `gh issue list`.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit <number>`.
- Close completed or declined work with `gh issue close <number>`.

When an engineering skill says to publish something to the issue tracker, create a GitHub issue in `PheadDodo/Green_CV`. When it says to fetch the relevant ticket, read the corresponding GitHub issue and its comments.
